# RESOURCES.md format

`RESOURCES.md` lists the sources that the lessons draw on. Facts come from
here, never from memory alone. Wisdom comes from the communities listed here.

## Template

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ by Author](https://example.com)
  What it covers. Use for: the questions it answers best.

## Wisdom (communities)

- [r/example](https://reddit.com/r/example)
  Why it is trusted. Use for: the help it gives.

## Gaps

- {An area that the mission needs and no good source covers}
```

## Rules

- **Trusted sources only.** Prefer primary sources, known experts, reviewed
  work and communities with strong moderation. Leave out marketing that looks
  like teaching.
- **One line of notes for each entry.** A bare link says nothing in three
  months. Give what it covers and when to use it.
- **Keep Knowledge and Wisdom apart.** A source can sit in one group only.
- **Name the gaps.** A gap in the list drives the next search.
- **Prune.** Remove a source that proved wrong, shallow or off the mission.
  Five sharp sources beat thirty weak ones.
- **Record opt-outs.** When the user declines communities, write that here, so
  no later session proposes them again.
