# GLOSSARY.md format

`GLOSSARY.md` is the one vocabulary of the workspace. Lessons, quizzes and
learning records all use its terms. A user who can compress a concept into a
tight definition shows that they understand it.

## Template

```md
# {Topic} Glossary

{One or two sentences on what the glossary covers.}

## Terms

**Progressive overload**:
Raising the demand on a muscle over time, by load, volume or intensity.
_Avoid_: Pushing harder, levelling up
```

## Rules

- **Add a term only when the user can use it correctly.** The glossary records
  what the user knows. It is not a dictionary to learn from.
- **Choose one word.** When several words name an idea, pick the best and list
  the others under _Avoid_.
- **Keep each definition to one or two sentences.** Say what the term is, not
  what it does.
- **Use glossary terms inside definitions.**
- **Group terms under subheadings** when clusters appear. A flat list is fine
  when the terms belong together.
- **Flag a loose term.** When the field uses a word in several ways, write which
  meaning this workspace uses.
- **Update in place.** A definition from week one can be wrong in week six.
  Never leave a stale entry.
